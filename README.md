# Social Media Backend API

A scalable Social Media Backend API built with **Node.js, TypeScript, Express.js, and MongoDB**.

This project provides backend services for a social media platform, focusing on secure authentication, user management, cloud-based file storage, and real-time communication.

The application follows a modular backend architecture designed to support maintainability, scalability, and efficient data management.

## 🚀 Technologies & Tools

| Technology | Purpose |
|---|---|
| Node.js | JavaScript Runtime Environment |
| TypeScript | Static Typing and Code Reliability |
| Express.js | Backend Web Framework |
| MongoDB | NoSQL Database |
| Mongoose | MongoDB Object Data Modeling |
| Zod | Schema Validation |
| JWT | Authentication and Authorization |
| Bcrypt | Password Hashing |
| Redis | Caching and Temporary Data Storage |
| Multer | File Upload Handling |
| AWS S3 | Cloud File Storage |
| Socket.IO | Real-Time Communication |
| GraphQL | API Query Language |

## ✨ Key Features

### 🔐 Authentication & Authorization
- User Registration and Login.
- Secure Password Hashing using Bcrypt.
- JWT-Based Authentication.
- Role-Based Authorization.
- OTP Verification.
- Temporary OTP Storage using Redis with a 5-minute expiration.

### 👤 User Management
- User Profile Management.
- Profile Picture Uploading.
- Secure File Access using AWS S3 Presigned URLs.

### ☁️ File Management
- File Upload Handling using Multer.
- Cloud Storage Integration with AWS S3.
- Presigned URL Generation for Secure File Access.

### 💬 Real-Time Communication
- Socket.IO Integration.
- Dedicated Socket Namespace.
- Real-Time Chat and Messaging Architecture.
- Redis-Based Socket Connection Management.

### ⚡ Performance & Security
- Redis Integration for Temporary Data Storage.
- Environment-Based Configuration.
- Request Validation using Zod.
- Secure API Authentication and Authorization.
